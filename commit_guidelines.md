# Git Commit Guidelines

We use **Conventional Commits** to keep our Git history consistent and easy to understand.

## Format

<type>: <short description>

## Types

- `feat:` — New functionality
- `fix:` — Bug fix
- `refactor:` — Code changes that don't change behavior
- `docs:` — Documentation
- `test:` — Tests
- `chore:` — Maintenance/configuration

## Examples

feat: add maze generation
fix: prevent solver from revisiting cells
refactor: simplify maze representation
docs: update project README
test: add solver path tests
chore: add gitignore

## Guidelines

- Keep commits small and focused.
- Use the imperative mood: `add`, `fix`, `update`.
- Keep descriptions short.
- Don't mix unrelated changes in one commit.
