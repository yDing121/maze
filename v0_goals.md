# Maze Generator & Solver

## Overview

Build a Python application that can **generate random mazes and solve them**.

The project should start as a local application, with a structure that could eventually support a web-based frontend.

## Requirements

### Maze Generation

The program must be able to:

- Generate random rectangular mazes.
- Support different maze sizes.
- Have a designated start and end point.
- Guarantee that the maze can be solved.

### Maze Solving

The program must be able to:

- Find a path from the start to the end.
- Avoid walls.
- Keep track of explored locations.
- Display the final solution.
- Implement the solving algorithm ourselves rather than using an existing maze-solving library.

### Frontend

The frontend should allow the user to:

- Generate a new maze.
- View the maze.
- Start the solving process.
- See the solution.

The maze should clearly distinguish walls, open spaces, the start, the end, and the solution.

### Backend

The backend should handle:

- Maze representation.
- Maze generation.
- Maze solving.
- Basic solution statistics.

The frontend and backend should be kept reasonably separate so that the frontend can eventually be replaced with a web-based interface.

## Constraints

- Python
- Core algorithms written by us
- No AI coding agents
- External documentation and libraries are allowed where appropriate
- Target completion time: approximately **one week**

## Optional Extensions

If the core project is finished early, we can add things such as:

- Solving animation
- Multiple solving algorithms
- Multiple maze-generation algorithms
- Algorithm comparisons
- Adjustable maze size and speed
- User-controlled maze solving
- Web-based frontend

## Goal

By the end of the project, we should have a small, working application that can:

**Generate → Display → Solve → Visualize**

and that we can continue expanding if we enjoy working on it.
